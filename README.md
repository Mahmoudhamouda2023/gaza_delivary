# Gaza Delivery — Store delivery 1.1 / Laravel 12 / MySQL

An Arabic merchant portal with local 10-digit phones, 8-character minimum passwords, scheduled deliveries, admin-managed neighborhoods, bicycle/electric-bicycle captains, verified digital receipt recording, and configurable captain/office fee splits. See README_AR.md for installation and docs/STORE_UPDATES_AR.md for upgrading and payment accounting. No default accounts, business data, or live payment-provider integration are bundled.
